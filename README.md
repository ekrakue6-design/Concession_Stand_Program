
# Concession Stand Program 🍿

## About
This is a Python project that simulates a simple concession stand ordering system.

## Features
- Displays a menu of available items.
- Allows customers to select items.
- Calculates the total cost of purchases.
- Uses a simple menu and cart system.

## Technologies Used
- Python

## Concepts Practiced
- Variables and data types
- Conditional statements
- Loops
- User input
- Basic programming logic

## Purpose
This project was created to strengthen my Python programming skills and develop problem solving abilities.
